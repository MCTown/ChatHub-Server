# ChatHub 控制台

控制台与 ChatHub 共用 HTTP 端口，默认打开 **http://127.0.0.1:6700/**。
无前端框架、无 CDN 资源；`web/` 中的静态文件由构建脚本复制到 `server/dist/web/`。
`npm run dev` 直接读取源码资产，修改页面后刷新即可；生产构建运行 `npm run build && npm start`。

## 登录

在 `server/config.yaml` 设置独立管理凭证：

```yaml
dashboard_token: "替换为独立的高强度随机密码"
```

也可通过 `CHATHUB_DASHBOARD_TOKEN` 覆盖。配置修改需要重启。
未设置该项时，页面仍可访问，真实数据 API 返回 503，不回退到节点或 OneBot 凭证。
不要使用示例密码公开部署；公网必须使用 HTTPS / WSS 反向代理。

### 反向代理下的管理操作

管理接口只校验独立 Bearer Token，不校验请求来源，因此可经反向代理访问，无需按代理域名维护来源白名单。
服务端不返回 CORS 响应头，其他网站无法读取管理接口响应；仍必须使用独立 `dashboard_token`。

页面将凭证保存在当前标签页的 sessionStorage（不可用时仅保存在内存），不写入 URL、
localStorage 或 Cookie。退出清除凭证及当前数据。不同用途的凭证应设置不同值。
未登录只显示独立登录页；服务端验证通过后才显示工作台。
刷新页面会重新验证当前标签页保存的凭证，验证完成前不会展示工作台。
登录失败停留在登录页；退出或凭证失效会清空工作台数据并返回登录页。无免登录演示入口。

## 页面

登录页和工作台右上角提供太阳 / 月亮按钮，切换蓝白浅色与深蓝暗色主题。
首次访问跟随系统配色；手动选择后在当前标签页的 sessionStorage 中保存，刷新后仍生效，
退出登录不清除主题。存储不可用时仅记住本次页面的选择，不影响认证或数据刷新。

- **平台总览**：在线节点、去重在线玩家、内存缓存消息、OneBot 通道数、连接拓扑、运行指标。
- **客户端与成员**：搜索已连接的 Minecraft / OneBot 客户端，查看玩家 UUID 或 QQ 成员账号。
- **消息流**：最近 150 条消息链路，一条源消息一张流程图；箭头与分支连线展示 Core、插件转发、客户端投递及 OneBot 上报，颜色区分确认、发送和异常。按来源、涉及节点和文本 / ID 筛选，点击节点只查看并复制该节点的脱敏报文，不展示整条链路 JSON。图较宽时可横向滚动，手机同样支持。
- **群聊**：独立 QQNT 风格聊天工作区 `/chat`，搜索与切换在线虚拟群、查看消息与成员，发送文字及图片；不替代原有观测页面。
- **日志**：最近 200 次发送失败，显示时间、目标客户端、投递 / 来源消息 ID 和失败原因；支持按来源、目标客户端与关键词筛选，总览也展示最近失败。
- **平台插件**：统一列表展示名称、模块名、说明、类型与状态；每个插件提供“开启 / 关闭”及“设置”按钮。设置弹窗中也提供开关；OneBot 可填写表单并添加 / 移除群客户端，跨服转发策略仍只读，不支持任意插件热加载。
- **平台设置**：管理通用的平台公网地址，编辑后自动保存；仅显示输入框与保存状态。
- **接入指南**：MCDR / OneBot 配置示例，可复制并替换占位密码。

默认每 5 秒刷新，可暂停或手动刷新；后台标签页暂停自动请求。
失败时保留上一次数据并明确标记过期；认证失败时清空数据并要求重新登录。

### 页面路由与动效

导航使用实际路径：总览 `/`、客户端 `/nodes`、消息 `/messages`、群聊 `/chat`、日志 `/logs`、插件 `/plugins`、设置 `/settings`、指南 `/guide`。
点击导航不整页重载，URL 与标题、当前导航状态同步；支持复制链接、新标签页、直接访问、刷新及浏览器前进 / 后退。
深链接仍先验证管理凭证；登录成功后进入所请求的页面，退出后不会因浏览器后退而展示已清除的数据。
服务端只为这些明确的页面路径返回前端入口，未知 API、资源与文件路径仍返回 404。

页面切换使用轻微淡入与上移；设置窗口与成员详情打开时有独立入场动画，手机导航及按钮有短过渡。
自动刷新、筛选、填写表单不会反复触发入场动画；快速切换会取消旧动画。
遵循系统“减少动态效果”偏好，缺少动画 API 时直接展示内容，不影响导航或操作。

OneBot 接入填写 V11 Universal 正向 WS 地址、群号与可选 Token，保存后即时连接，重启恢复。
配置及 Token 保存在服务端受限文件，不在列表回显。详见 [OneBot 客户端适配器](onebot-client-adapter.md)。
关闭弹窗保留非敏感表单草稿，并清除未提交的机器人 Token；自动刷新不关闭窗口或重置填写内容，退出或认证失效会关闭窗口。
弹窗支持 Esc 关闭、键盘焦点限制和关闭后返回设置按钮；总览中的“查看配置”也直接打开同一窗口。
列表与弹窗均支持明暗主题和窄屏布局。
插件名单、版本、类型与说明来自服务端注册表；声明 `editor` 的插件自动获得 Schema 驱动的配置表单，
无可编辑声明的新插件使用安全的只读配置快照。表单字段、默认值、范围和类型来自服务端，不由前端重复维护。
插件开关即时生效，保存在 `server/data/plugins.json`（plugin_state_file），重启后恢复，优先于 plugins.<id>.enabled 初始配置。
关闭跨服转发不影响已连接的群或应用网关；关闭 OneBot 会中止连接、重连及等待中的投递，但保留群客户端配置。
关闭期间仍可保存 / 移除 OneBot 客户端，开启后连接所有保留客户端；关闭 OneBot 前会弹出确认。
操作等待中防止重复点击，失败不伪造成功状态；状态过期或旧版本服务端不支持开关时禁用按钮。
**dashboard_token 可发送群消息、管理外连客户端与平台插件开关，不应分享给只读访客。**

### 群聊工作区

从导航“群聊”或直接访问 `/chat` 进入；使用同一独立管理登录，不获取或复用 `node_password` / `onebot_token`，也不调用网关凭证详情接口。
桌面显示群列表、对话与成员；窄屏通过“返回群聊列表”切换群。Enter 发送、Shift+Enter 换行，中文输入法选词时不会误发。
每群文字与图片草稿仅保存在当前工作区内存中，轮询保留输入焦点与滚动位置；离开页面、退出或认证失效时清除。
发送等待客户端确认，成功后立即插入返回的消息；失败保留草稿，快照过期时禁止发送。系统消息、应用消息和插件投递均可查看。
联系人、收藏、群设置等占位按钮明确提示暂未开放，不生成虚假群或消息。

图片选择后可预览、移除；支持 PNG / JPEG / GIF / WebP，原始单张最多 5 MiB。
发送前必须在“平台设置”配置客户端 / ChatImage 可下载的 HTTP(S) `public_url`；浏览器把图片编码为 `base64://...`，服务端通过共享 OneBot API 调用 `ImageStore.ingest()` 校验并存储，投递时仅使用公开 URL。
聊天仅加载当前浏览器同源 `/media/images/` 图片，任意远程图片 URL 显示 `[图片]`；若 `public_url` 与控制台不同源，图片仍可投递，但聊天页不会加载该远程地址。

### 指标边界

在线客户端包含已连接的 Minecraft 节点和验证成功的 OneBot 群客户端，不包含等待重连的配置。
Minecraft 不维护离线注册表；OneBot 插件单独保存其管理配置。
在线玩家按稳定虚拟用户 ID 去重；成员列表包含观察到的离线玩家，不是完整玩家数据库。
Minecraft 在线状态来自服务端调用客户端 get_online_players 的最近成功结果，不由聊天或进出服通知推断。
注册后立即查询，成功后每 5 秒再次查询；查询失败 / 超时移除该在线群并让节点重连。
OneBot 成员仅为本次连接中发言者，展示 QQ 账号，不伪造 UUID / 在线状态，也不计入在线玩家。
消息数是当前进程的缓存条数（最多 1,000），不是历史累计或速率。
OneBot 连接数是 WebSocket 通道数，API / Event 分离连接分别计数，不等于应用数量。
节点断开后已缓存消息仍可查看，群名可能显示为群 ID。重启清空消息缓存。
应用 / 插件投递仅在节点 ACK 后入缓存；ACK 不保证玩家实际收到。

### OneBot 收发记录

只记录 **ChatHub 对外抽象出的统一 OneBot V11 接口**（`/onebot/v11` 及 API / Event 通道，包括反向应用连接）的 WebSocket JSON 收发，不记录真实 QQ 机器人适配器的上游 API 通信。
接收是 **应用 → ChatHub** 的 API 调用；发送是 **ChatHub → 应用** 的群消息事件、API 响应及生命周期 / 心跳元事件。
其中群 / 用户 ID 是 ChatHub 的平台虚拟身份，不是上游 QQ 群号 / 账号。`payload` 为协议数据，另附连接标识、接口名称、调用 action 和记录时间。
请求与响应保留 `echo` 便于对应；Token、Authorization、password 等敏感字段递归脱敏，不记录握手凭证。
过大的内容会截断并标记 `truncated`，非 JSON 报文仅显示诊断提示、不保留原文。
这些记录只用于观测，不进入平台聊天缓存、不触发转发、不计入聊天消息数；最多保留 200 条，重启清空。

### 消息链路

`traceId` 仅在服务端内部使用，不改变 native v2 或 OneBot V11 协议，也不改变事件总线和转发规则。
客户端聊天 / 系统消息在 Core 入站时创建链路，记录平台消息 ID、客户端身份及 native event_id；
CrossServerRelay 复用源链路，并为每个目的地记录插件名、处理耗时和最终确认结果。
native 投递及 ACK 的 request_id、报文可在步骤详情中查看。失败和超时也留在源链路中，不要求投递成功才可见。
客户端已确认表示 MCDR ACK / 外部机器人 API 接受，不保证玩家看到。

统一 OneBot 网关为每次请求创建独立链路，直接关联 Core、应用投递及 API 响应；不依赖 echo 唯一性。
消息事件上报复用入站消息的链路，每条应用连接分别记录分支。生命周期 / 心跳元事件有独立链路。
WebSocket 回调成功仅标记“已发送（未确认处理）”，没有应用端 ACK 不标记为已处理。
普通聊天也会向已连接的 OneBot 应用上报，展示真实路径，不按 /help 等内容推测处理规则。
外部应用返回的回复与触发它的玩家消息不能自动跨应用关联；没有明确因果字段时显示为两条链路。
不记录真实 QQ 机器人适配器的上游 API 通信，也不把观测步骤发布为聊天事件。

每个进程保留最近 1,000 条链路，重启清空，非持久审计日志。
每条最多 100 个步骤、24,000 字符的 JSON 报文快照；超过上限明确标记截断。
每 5 秒只刷新最近 150 条摘要（无步骤 payload）；打开详情才读取报文，窗口保留此刻快照，不打断展开与文本选择。
图中包含投递报文、ACK 和确认等子步骤（虚线卡片表示客户端收发报文），点击任意节点只显示该节点的 `payload`；
没有报文快照的 Core 等内部步骤会明确提示，不回退到源消息、不合并相邻步骤。
标题默认打开来源节点；复制按钮仅复制所选节点的报文，缺少快照时禁用。轮询保留链路图的横向滚动位置。
旧版服务端没有 traces 字段时，页面回退到原有消息流。

### 发送失败日志

跨客户端转发和应用调用的投递在平台核心统一记录失败，包括客户端拒绝、确认超时、
发送期间断线，以及向离线 / 未知群投递。一次失败仅记录一条，不影响其他客户端的转发。
统一 OneBot 网关在投递前的消息准备失败也会记录，包括未设置公网地址、base64 编码 / 图片校验失败、图片缓存满额及存储失败；此时还没有投递消息 ID。
日志独立于消息流，不会被当作聊天转发；失败投递不会进入已接受的消息缓存。
已连接目标的名称和客户端 ID 随失败记录保留，目标断开后仍可查看；离线 / 未知群以群 ID 显示。
仅保存失败原因与定位信息，不保存失败消息正文或错误堆栈。
日志仅保留在当前进程内存中，最多 200 条，最新在前；服务端重启后清空，不是持久审计日志。
日志与其他状态一起每 5 秒刷新，暂停刷新也会暂停日志更新。

## API 与安全边界

### 群消息发送

`POST /api/chat/messages` 要求 `Authorization: Bearer <dashboard_token>`、`Content-Type: application/json` 及与管理操作相同的 Origin 校验；不接受 query token 或其他用途凭证。

```json
{"group_id": 123456, "text": "你好", "image": "base64://..."}
```

只接受这三个字段：`group_id` 是在线虚拟群的正整数 ID（不是上游 QQ 群号）；`text` 最多 8000 字符，可省略；`image` 是可选的一张 base64 图片，不接受远程 URL。文字与图片至少有一项。
群列表和发送均复用 ChatHub 共享 `OneBotApi`，与网关 `get_group_list` / `send_group_msg` 使用同一平台路由、图片管线、投递确认及跨服转发策略，Dashboard 不直接调用 `Platform.send()`。
成功确认后返回 HTTP 201 `{message: ...}`；请求无效 / 群离线 / 图片校验失败返回 400，认证失败 401，来源拒绝 403，非 JSON 415，投递异常 502。失败不会进入成功消息缓存。
成功发送不伪造入站消息事件；开启跨服转发时按共享 OneBot API 的成功应用发送规则转发。

### 平台设置

公网地址是平台基础配置，不绑定图片转发。页面停止输入 600 毫秒或离开输入框后自动保存，
显示保存中旋转指示与保存完成勾选动画；遵循“减少动态效果”偏好。没有保存按钮或图片参数说明。
保存期间可继续编辑，新值按顺序提交，不会被旧请求结果覆盖；轮询不重建输入框或重播保存动画。

`GET /api/settings` 返回 `{settings: {public_url, revision}}`；`PUT /api/settings` 使用相同结构保存，
要求 Dashboard Bearer Token、JSON 请求体和与其他管理操作一致的来源校验，不接受未知字段。
revision 不匹配返回 409，防止覆盖其他管理员的修改；页面保留草稿并提示刷新页面后重试。
`GET /api/dashboard` 也包含 `settings` 快照，但不暴露私有文件路径。

设置默认持久化到 `server/data/settings.json`（0600、原子写入），优先于启动时
`server/config.yaml` 的 `public_url` / 环境变量 `CHATHUB_PUBLIC_URL` 初始值。
`settings_file`、`image_directory` 可在 YAML 修改私有存储位置；修改路径需要重启。
公网地址只允许 HTTP(S) 来源（可含端口），不由请求 Host / 转发头自动推断。
它不改变监听端口、鉴权或代理配置。
没有单独配置 `onebot_public_url` 时，OneBot 连接详情显示由平台公网地址派生的 WS / WSS 网关地址；显式 `onebot_public_url` 始终优先，避免图片下载地址覆盖独立的网关部署地址。

### 公开图片

图片存储通过注入的地址读取函数使用平台公网地址，不依赖设置持久化或编辑逻辑。
`GET /media/images/<随机文件名>` / HEAD 是公开下载接口，无需 Token，不允许上传或列目录。
仅提供校验后的 PNG / JPEG / GIF / WebP，阻止路径遍历及符号链接，带正确 MIME、nosniff 和限制性 CSP；
过期 / 不存在的文件返回 404。大小、格式、有效期和缓存限制详见 [OneBot 图片说明](onebot-v11.md#base64-图片与-chatimage)。

### 状态与诊断 API

`GET /api/dashboard` 使用 `Authorization: Bearer <dashboard_token>`，不接受 query token。
返回版本、运行时长、RSS 内存、群 / 玩家状态、消息快照、OneBot 收发记录（`onebotTraffic`）、发送失败日志（`logs`）、转发配置和协议路径。
另返回 `traces` 链路摘要；`GET /api/traces/<traceId>` 使用相同的独立 Dashboard Bearer 鉴权，
按需返回完整脱敏链路，已过期 ID 返回 404；无 CORS，响应不缓存。
页面使用 `/api/dashboard?trace_view=1`，省略旧版 messages / onebotTraffic 报文列表，避免轮询重复传输报文；
不带该参数的 API 保留兼容字段。
群聊使用 `/api/dashboard?trace_view=1&chat_view=1` 获取最多 1000 条最近消息，其他页面仍使用轻量快照。
不返回密码、机器人 Token、完整配置、身份映射文件或反向应用地址。OneBot 客户端展示无凭证的 WS 地址。
总览的 OneBot 应用连接卡片、拓扑中的 OneBot 接口可点击，打开接入详情弹窗：当前访问地址、
服务端内网直连地址、有效 OneBot Token 与统一 self_id，并支持复制地址 / Token。
弹窗仅保留“连接地址”和“鉴权与机器人身份”两部分，不显示鉴权方式、完整配置或插件身份说明。
使用 `onebot_public_url`（或 `CHATHUB_ONEBOT_PUBLIC_URL`）配置公网 Universal WS 地址，
从内网访问控制台时也会显示该公网地址。地址统一去重；Web 地址与内网或公网地址相同时只显示一项。
部署更新后须重启 ChatHub 服务端，避免新静态页面调用旧进程而返回 404；不必重启 Minecraft。
Token 默认遮蔽，点击显示后可手动复制；关闭、切换页面或退出会清除弹窗数据，不写入浏览器存储。
仅打开弹窗时调用 `GET /api/onebot/connection`，使用独立 Dashboard Bearer 鉴权及 Origin 检查、
不缓存、不开放 CORS。这是唯一主动返回网关 `onebot_token` 的管理入口；不返回节点密码、
控制台 Token 或真实 QQ 机器人凭证，总览快照与静态资源仍不包含凭证。
该凭证可以读取玩家 UUID、QQ 成员账号和聊天内容，
应视为敏感凭证。API 无跨域授权、响应不缓存。

观测 API 仍只读。新增的 `POST /api/plugins/onebot/clients`、`DELETE /api/plugins/onebot/clients/<id>`
仅管理 OneBot 群客户端；`PUT /api/plugins/onebot/state`、`PUT /api/plugins/relay/state` 接受严格的
`{"enabled": true}` / `{"enabled": false}`，只控制两个内置插件的开关，并执行相同的认证及 Origin 检查。
`GET /api/plugins` 返回注册插件的公开元信息及配置投影；Dashboard 快照包含同一 `plugins` 列表，以及
`pluginStates` 和当前有效的 relay.enabled 等兼容字段，不回显配置文件路径或私有凭证。
不提供控制 Minecraft 节点、安装任意插件或任意配置写入的接口；群消息仅通过上述受限接口发送。注册与配置规则见 [插件规范](plugins.md)。
配置编辑使用 `GET/PUT /api/plugins/<id>/config`，带 schemaVersion 与 revision；服务端严格校验并防止并发覆盖。
静态资源使用明确路径白名单和 CSP，动态文本转义；观测页消息图片 / URL 只显示文字，群聊只加载同源媒体图片。
跨服转发仍由服务端插件负责；群聊不绕过插件策略，不会将应用 / 插件投递重新发为输入事件。
